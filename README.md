# CyberZonaRND Bot

Телеграм-бот для бронирования ПК в компьютерном клубе, уведомлений администратору и выдачи справочной информации.

## Возможности
- Главное меню: бронирование, просмотр/отмена брони, поддержка, инфо, ссылки.
- Бронирование:
  - выбор ПК (1–26);
  - выбор даты (ввод или кнопка «Сегодня»);
  - выбор времени начала;
  - выбор длительности (1/3/5/7/10 часов);
  - проверка доступности в локальной БД;
  - подтверждение через inline-кнопку; создание записи в БД; уведомление администратору.
- Управление бронью:
  - «📋 Мои брони» — список активных броней пользователя;
  - «❌ Отменить бронь» — удаление последней брони и уведомление администратору.
- Поддержка:
  - кнопка «💬 Поддержка» — пользователь отправляет сообщение; бот пересылает администратору.
- Информация:
  - «💰 Прайс-лист» — тарифы по зонам (Standart, Bootcamp, VIP, PlayStation) с будни/выходные и день/ночь;
  - «🎁 Акции и бонусы», «🏆 Расписание турниров», «📜 Правила клуба».
- Ссылки:
  - ВК, мобильное приложение, чат/группа для турниров.

## Основные команды и кнопки
- `/start` — показать главное меню.
- Кнопки главного меню:
  - `🎮 Забронировать ПК` — запуск сценария бронирования (ПК → дата → время → длительность → подтверждение).
  - `📋 Мои брони` — вывести все активные брони пользователя.
  - `❌ Отменить бронь` — отменить последнюю бронь пользователя.
  - `💬 Поддержка` — отправить сообщение админу.
  - `ℹ️ Информация` — прайс, акции, турниры, правила.
  - `🔗 Ссылки` — быстрые ссылки (ВК, приложение, турниры).

## Хранение данных
- Локальная БД `club.db` (aiosqlite), таблица `bookings`:
  - `id`, `user_id`, `pc_number`, `date`, `time_from`, `time_to`.
- Проверка доступности: запрос по ПК, дате и пересечению интервала времени.
- Отмена/просмотр: выборка последней или всех броней пользователя.

## Уведомления администратора
- Переменная `ADMIN_ID` в `bot.py`.
- Уведомления отправляются при:
  - создании брони;
  - отмене брони;
  - сообщении в поддержку.
- Администратор должен запустить бота (написать `/start`), иначе сообщения не доставятся.

## Прайс (пример)
- Зоны: Standart, Bootcamp, VIP — будни/выходные + день/ночь, набор тарифов.
- PlayStation: Standart/VIP с тарифами.
- Время дня/ночи: день 10:00–22:00, ночь 22:00–10:00 (при необходимости меняется в коде).

## Запуск
1. Установить зависимости:
  
   pip install aiogram aiosqlite
   2. Указать токен бота в `TOKEN`, ID админа в `ADMIN_ID`.
3. Запустить:
  
   python bot.py
      При первом запуске создастся БД `club.db`.

## Структура сценария бронирования
1. `🎮 Забронировать ПК`
2. Выбор ПК → выбор даты → выбор времени → выбор длительности
3. Проверка доступности
4. Подтверждение (inline «✅ Подтвердить» / «❌ Отменить»)
5. Создание записи, уведомление админа, вывод деталей пользователю.

## Полезные заметки
- Если возникает ошибка «Conflict: terminated by other getUpdates request» — убедитесь, что запущен только один экземпляр бота.
- Для исправления недоставки сообщений админу — проверьте `ADMIN_ID` и что админ отправил `/start`.
